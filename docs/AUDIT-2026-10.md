# Audit and migration report: catalogue v1 → Atlas v2

Date: 2026-10-15 · Branch: `dev/atlas-modernization` · Baseline: `main` at `a5775f0`

## 1. Repository audit (v1)

| Area | Finding |
| --- | --- |
| Structure | 3 files: `index.html`, `htkkh_reference_ontologies_map_catalog.json`, `htkkh_reference_ontologies_map.ttl`. No build, tests, CI or docs. |
| Data duplication | The 26 records were maintained three times: in the JSON file, in the TTL file, and inline in `index.html`. The copies could drift apart. |
| **Confidentiality** | Every record had a `wiki` URL pointing to an internal 3DEXPERIENCE community wiki (26 links), and the page header linked to that community. These were published on a public site. |
| RDF | The TTL namespace used a placeholder domain (`goodcompany.com`). |
| UI | A single page with filter dropdowns and cards, without detail pages, deep links, graph, dark mode or accessible navigation. |
| Taxonomy | Mixed "Core" and "End-Object" categories. Every High-Tech core record was mapped to all four end objects, so the mapping could not tell records apart. |

## 2. Record-level findings and corrections

| v1 record | Issue | v2 resolution |
| --- | --- | --- |
| CIM | Publisher was "IEC", but the description and use (IT racks, chassis, processors) are the **DMTF** CIM. These are two different standards. | The record is now `dmtf-cim` (DMTF, CIM Schema 2.54.1). The IEC power-system CIM was added separately as `iec-cim`. |
| CORA | The official link pointed to an unrelated smart-appliances project page. | Now links to IEEE 1872-2015, plus the CC BY 4.0 OWL conversion. |
| Autonomous Robotics (AuR) | Listed as "Research / Community, not stable". | It is a published standard, IEEE 1872.2-2021 (published 2022-05-12). |
| Robot Task Representation | Listed as "Research / Community, not stable". | It is a published standard, IEEE 1872.1-2024 (published 2024-06-18). |
| CORAX, POS, RPARTS | Listed as "Research / Community, not stable". | These are modules specified in IEEE 1872-2015. |
| SUMO-CORA | Unclear status. | Linked to IEEE 1872-2015; marked partially verified. |
| GS1 WebVoc | Marked "licensed". | Published under Apache 2.0, so now open. |
| ORIONT | No public ontology found under that name. The description refers to the ORIENTING H2020 project. | Kept as an **unverified** candidate (`needsReview`), with CORDIS cited as context. |
| GoodRelations | Treated as current. | Integrated into schema.org in 2012; maturity set to legacy. |
| OWL-Time | — | Version recorded as the W3C Candidate Recommendation Draft of 2022-11-15. |
| All 26 | No version, licence or verification date. | Added version, licence, formats, namespace and sources, with `checkedOn` 2026-10-15. |

All 26 v1 records are preserved. Each v2 record keeps its original fields in a `legacy` block, which tests check
against `data/legacy/catalog-v1.json`. The only change to the original fields is that internal wiki URLs were replaced
by `hasInternalWikiLink: true`.

## 4. Scope: vendor-neutral

At the owner’s request the atlas is generic: it contains no software-vendor, product or brand mappings and no adoption
claims. A test enforces this.

## 5. Open items requiring the owner's decision

1. **Git history.** The internal wiki URLs are removed from all current files, but they remain in earlier commits on
   `main`, which are public. Removing them from history requires a history rewrite (for example with `git filter-repo`)
   and a force-push. That would break existing clones and commit links. It has **not** been done.
2. **Licence of this repository.** There is no LICENSE file. Choose one for the code (for example MIT) and one for the
   data (for example CC BY 4.0) if you want others to reuse them.
3. **Records to review:** ORIONT (no public source), plus all `partially-verified` records. Filter by
   *Verification* in the catalogue to see them.
4. **Deployment.** GitHub Pages serves `main` from the repository root. Merging this branch publishes v2 at the same URL.
